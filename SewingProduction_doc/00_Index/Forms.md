# Формы и пользовательские инструкции

Встроенная справка открывает файл по типу активной формы:

~~~
Help/{namespace без SewingProduction}/{FormName}.html
~~~

Например, для SewingProduction.Features.Sprav.Forms.ThreadNormsForm ожидается:

~~~
Help/Features/Sprav/Forms/ThreadNormsForm.html
~~~

## Правило покрытия

Для каждой формы из меню фиксируется один из статусов:

| Статус | Значение |
|---|---|
| Документирована | Есть статья в 05_UserGuide и сгенерированный HTML. |
| Наследуемая | Есть прежняя HTML/DOCX-инструкция; её нужно перенести в Markdown при ближайшей правке. |
| Не требуется | Форма техническая, административная или не доступна конечному пользователю. |
| Требуется | Пользовательская форма без инструкции. |

## Первая статья нового формата

- [[ThreadNormsForm]] — норма ниток; статья публикуется в HTML-help генератором.

Список форм из SpMainForm и фактический состав Help пересматривается при изменении меню. Не нужно автоматически создавать инструкции для всех классов: в репозитории есть служебные и дизайнерские формы.
