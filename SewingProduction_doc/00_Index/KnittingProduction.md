# Вязальное производство

Модуль расположен в Features/KnittingProduction.

Основные точки входа из главного меню:

- планирование вязального производства;
- PlanZagrVyaz;
- KnitterWorkSpace;
- аналитика вязального производства.

В модуле сосуществуют legacy-формы и прикладной слой для отдельных сценариев. При точечной доработке сохраняйте стиль конкретной формы, не переносите SQL в UI и не создавайте новые partial-файлы.
