Назначение ролей пользователю

Форма предназначена для назначения ролей пользователям системы.

Слева отображается список пользователей, справа — список ролей.

Порядок работы:

  • Выберите пользователя в левой таблице.
  • После выбора пользователя загрузятся его роли.
  • Отметьте галочками нужные роли.
  • Снятие галочки удаляет роль у пользователя.

Описание элементов:

  • Пользователи – список пользователей системы.
  • Роли – список доступных ролей.
  • Выбор – галочка назначения роли.

Особенности:

  • Можно выбрать только одного пользователя одновременно.
  • Роли применяются сразу после изменения (без кнопки "Сохранить").
  • Роли автоматически группируются на:
    • Назначенные
    • Доступные

Горячие клавиши:

  • ↑ ↓ – перемещение по пользователям.
  • → – переход к ролям.
  • ← – возврат к пользователям.
  • Enter – переключение роли.
