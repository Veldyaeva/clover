Нормы ниток

Форма предназначена для просмотра и корректировки норм ниток по ассортименту.

Открытие

Откройте раздел Справочники и выберите пункт Нормы ниток.

Работа со списком

  • По умолчанию отображаются строки с нулевой нормой — они требуют заполнения или проверки.
  • Используйте кнопку Все для просмотра полного списка.
  • Используйте Обновить, если данные были изменены другим пользователем.
  • После изменения значения нормы дождитесь завершения сохранения строки перед переходом к другой записи.

Если строка не сохраняется

  1. Проверьте обязательные значения в строке.
  2. Обновите список и убедитесь, что строка не изменилась другим пользователем.
  3. Зафиксируйте ассортимент, материал, текст ошибки и время возникновения.
  4. Передайте сведения ответственному за справочники. Не повторяйте сохранение вслепую, если ошибка сохраняется.
