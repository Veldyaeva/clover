Изменение данных в матрице

Форма предназначена для применения изменений набора к выбранным записям в матрице.

Слева отображается список наборов в матрице, справа — информация по выбранному набору и его составным частям.

Структура формы:

  • Наборы в матрице – список записей, к которым можно применить изменения.
  • Данные набора – информация по текущей выбранной строке.
  • Части набора – состав набора с возможностью перехода к изменению динамических признаков.

Порядок работы:

  • Выберите одну или несколько строк в таблице "Наборы в матрице".
  • При выборе строки справа отображаются данные выбранного набора.
  • Проверьте состав набора в блоке "Части набора".
  • При необходимости нажмите кнопку в колонке "Д" для изменения динамических признаков части набора.
  • После проверки нажмите "Сохранить" для применения изменений к выбранным номерам.

Особенности:

  • Изменения применяются только к выбранным номерам.
  • Если ни одна строка не выбрана, сохранение не выполняется.
  • Форма открывается после сохранения изменений в основной форме редактирования набора.

Дочерняя форма:

  • Изменение – форма редактирования динамических признаков выбранной строки или части набора.
