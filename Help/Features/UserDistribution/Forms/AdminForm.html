Форма "администрирования форм"

Данная форма нужна для добавления / редактирования / удаления форм и объектов из базы данных

Загрузить формы

Сканируется проект, найденные формы добавляются в базу данных.

Загрузить меню

Сканируются элементы меню, для сканирования необходимо выбрать главную форму.

Добавить форму

Добавление формы вручную (если сканирование не помогло).

Удалить форму

Удаление формы из базы данных (если форма устарела или неактуальна).

Открыть форму

Откроется экземпляр формы (если форма имеет необходимые параметры).

Загрузить объекты

Сканируется выбранная форма, в базу добавляются найденные объекты.

Добавить объект

Добавление объекта вручную (если сканирование не помогло).

Удалить объект

Удаление объекта из базы данных (если объект устарел или неактуален).
