Форма ролей

Форма для управления ролями

Для добавления / копирования / удаления нажмите соответствующую кнопку справа.

Для редактирования - необходимо дважды нажать на запись.

Для назначения прав доступа на определенную форму, необходимо раскрыть список форм как показано на рисунке,

в списке найти нужную форму, можно задать доступ для всей формы,

также можно раскрыть список объектов на форме и задать права для каждого объекта отдельно.

Для назначения роли пользователю - выберите вкладу "Пользователи",

поставьте "галочку" напротив пользователя, которому хотите назначить эту роль.
