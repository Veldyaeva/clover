Профиль

Форма предназначена для отображения и редактирования профиля текущего пользователя.

Ниже представлен список форм доступных из этой формы:

  • Пользователи - Список пользователей для редактирования и назначения им ролей.
  • Иерархия пользователей - Список пользователей, созданных нами и нашими "потомками".
  • Роли - Список ролей для администрирования.
  • Администрирование форм - Управление формами.
  • Администрирование таблиц - Управление таблицами.
  • Администрирование колонок - Управление колонками.
  • История действий - Список действий пользователей.
